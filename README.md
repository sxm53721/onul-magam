# 오늘마감 (가칭)

영종도 동네 가게의 **오늘 마감할인**을 찜한 손님에게 알려주는 PWA 프로토타입입니다.
지금 버전은 서버 없이 목업 데이터 + 브라우저 저장소로 돌아갑니다.

## 실행 (Windows PowerShell 기준)

```powershell
cd C:\ggg\vibecoding\onul-magam
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 휴대폰 화면으로 보려면 개발자도구(F12) › 기기 툴바(Ctrl+Shift+M).

## 둘러보기
1. **오늘 마감** 탭: 영종도 동네·업종 필터, 마감 임박순/할인율순 정렬
2. 할인 카드 → **상세**: 전화로 확인, 카카오맵 길찾기, 가게 찜
3. **사장님** 탭: 오른쪽 위에서 체험할 가게 선택 → 사진 찍고 가격·수량·마감 시각 입력 → 게시 → 피드에 바로 노출, 품절 처리
4. **찜·알림** 탭: 알림 권한 켜기, 테스트 알림 보내기

> 사장님이 올린 게시는 이 브라우저에만 저장됩니다. 실제 공유·푸시 발송은 Supabase 연결(2단계) 후 동작합니다.
